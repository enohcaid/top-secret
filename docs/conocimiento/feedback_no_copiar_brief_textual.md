When a user explains something in depth (a method, a position, a rule) as context/brief for content I'm about to write, I should absorb the substance and then write original, crafted copy in my own words — optimized for the actual format (social media caption, slide text, etc.). I should not lift their sentences near-verbatim and just shorten them.

**Why:** caught directly on the Juan Martinez Instagram project (2026-08-05) — several slide texts ("No aconsejo, no receto, no curo, comprendo", "humildad y autocrítica", "esto no es una pastilla", "no reemplaza... puede complementarlo") were close paraphrases of the user's own dictated explanation rather than copy I had actually crafted. The user's point: what they write in chat is a guide for me to understand and re-express well, not a draft to copy-paste.

**How to apply:** After receiving a detailed dictated brief, deliberately rewrite the core ideas using different sentence structures, metaphors, or framing than the source text before presenting it as "final" content — treat close-paraphrase as a smell that I skipped the actual writing step. This applies beyond this one project to any content-writing task where the user supplies substantial raw material (notes, transcripts, explanations) to be turned into polished output.
