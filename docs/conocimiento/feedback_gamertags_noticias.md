En el cuerpo de las noticias y captions de redes sociales, siempre usar el gamertag exacto tal como aparece en el array PLAYERS. Nunca abreviar ni usar variantes.

**Why:** "J. Martinez" o "RS32DaniStone" no se ven bien — el lector espera ver el nombre de juego del jugador, no una versión acortada.

**How to apply:** Antes de publicar cualquier artículo, verificar que cada mención de jugador coincida exactamente con el campo `name` en PLAYERS (ej: `Juan_Martinez4`, `RS32-DaniStone`, `CipriMancini`, `zPibu__`, `BlackPanther-CG`).
