**Script reutilizable (2026-10-05):** `node scripts/publicar-video.mjs youtube|x|tiktok <video.mp4> --texto "…" [--titulo "…"] [--hashtags "A,B"]` (capturas en `fuentes/redes/pub-<red>-*.png`). Instagram/Facebook: `scripts/meta.mjs ig-reel|fb-video <url R2> "<texto>"`. Con la música trap pegada al archivo se publica en las 5 redes sin pasos manuales (primer uso: presentación del plantel T4, 2026-10-05). Trampa de X: el botón Postear queda deshabilitado mientras procesa el video; el script espera a que se habilite (antes clickeaba antes de tiempo y no publicaba). TikTok toma como portada el primer cuadro: los videos de `scripts/video-plantel` arrancan con 2 cuadros de portada por eso.

Primera publicación automatizada: 2026-10-01, reel "Expediente Top Secret: desclasificado" (scripts en `fuentes/redes/` no versionados; esto es el resumen reutilizable).

- **YouTube** (sesión en el Chrome CDP, canal **TOP Secret FC** `UCEKzzKDMMPri12Q3E9S7IVw`; ojo: el perfil también tiene el canal personal de Juan): `studio.youtube.com/channel/<id>/videos/upload?d=ud` → `input[type=file]` → `#textbox` 0 = título, 1 = descripción → radio `VIDEO_MADE_FOR_KIDS_NOT_MFK` → `#next-button` ×3 → radio `PUBLIC` → `#done-button`. Vertical ≤60 s sale como Short. Resultado: https://youtube.com/shorts/7ykfCkHJuD8
- **X** (@FCTOPSecret): componer desde `x.com/home` (`tweetTextarea_0` + `input[data-testid=fileInput]`), esperar "…mp4: Listo", y publicar con `document.querySelector('[data-testid=tweetButtonInline]').click()` vía evaluate — el click normal de Playwright falla porque una capa del header intercepta el puntero; desde `/compose/post` tampoco salía. Verificar en el perfil (el primer post es el FIJADO del ascenso). Resultado: https://x.com/FCTOPSecret/status/2105657385352147409
- **TikTok** (@topsecretfc): `tiktok.com/tiktokstudio/upload` → `input[type=file]` → cerrar diálogos ("Cancelar" en revisiones automáticas, "Entendido") → descripción en el contenteditable (hashtags escribiendo `#x` + espacio) → "Editar portada" y arrastrar el selector a un cuadro con texto (el primer cuadro es negro) → Guardar → Publicar. Queda "Contenido en revisión / Solo yo" unos minutos y después pasa a público.
- **Instagram y Facebook:** el login en el Chrome CDP lo frena un captcha (también en modo normal). Juan sube a mano por ahora; alternativa: API de Meta (Graph API, publicación de Reels).
- Noticia en el sitio con video de YouTube: bloque de body `{youtube: '<id>', vertical: true, caption}` (noticias.html `bodyHtml`).

**Música (regla de Juan, 2026-10-01): los reels se suben con música de cada app.** Instagram/Facebook solo desde la app del celular (ni la web ni la API de Meta permiten la biblioteca de música) → Juan sube el video MUDO y elige el tema ahí. TikTok: editor web de TikTok Studio → "Sonidos" (buscar, "+", Guardar en el editor; la música no se puede agregar después de publicado → re-subir). YouTube: Studio → video → Editor → Audio → filtrar por título → "+" → Save → tildar "I acknowledge…" → Confirm changes (procesa minutos/horas, mantiene el link; solo Biblioteca de audio de YouTube, sin sonidos virales). X: no tiene biblioteca → pegar al archivo un tema de la Biblioteca de audio de YouTube (descargable desde Studio → Audio library) con ffmpeg (`loudnorm=I=-14`, `aresample=48000`).
Relanzamiento T4: TikTok + Instagram con **"Red Right Hand" (Nick Cave & The Bad Seeds, Remastered 2011)**; YouTube + X con **"Twin Lynches" (Density & Time, Biblioteca de audio)**. Links finales: YouTube https://youtube.com/shorts/7ykfCkHJuD8 · X https://x.com/FCTOPSecret/status/2105663153703170453

**API de Meta configurada (2026-10-01):** app "Top Secret FC Publicador" (id en `.env`), token de página **permanente** para la página TOP Secret FC + Instagram @fctopsecret (cuenta profesional vinculada). `node scripts/meta.mjs estado | ig-imagen | ig-carrusel | ig-reel | fb-foto | fb-video [--prueba]`. Probado con `--prueba` (crea el contenedor sin publicar). Sirve para placas, carruseles, noticias y reels **sin** música de biblioteca (primer uso real: carrusel "El expediente", 6 placas, https://www.instagram.com/p/Dd9_jBFgPap/ — `scripts/relanzamiento/carrusel.cjs`); los reels con música siguen siendo manuales desde la app. Si el token de página deja de servir (cambio de contraseña, permisos), regenerar el de usuario en Graph API Explorer y volver a derivar el de página (`/me/accounts`).

**Foto de perfil y portadas (2026-10-02/03).** Archivos finales en R2 `_fuentes/redes/perfiles/out/` (originales de ChatGPT en `.../originales/`; scripts `portadas-chatgpt.mjs` + `recortar.mjs` en `fuentes/redes/perfiles/`, no versionados). Foto de perfil = escudo New Metal recortado **exacto al círculo del badge** (diámetro 4457 px, centro 2471,2462 en `Top Secret Logo New.png`) para que el recorte circular de cada red caiga sobre el aro, sin margen. Portadas: un trío de jugadores T4 por red generado en ChatGPT con grilla fija (texto 6–31% del alto, caras 33–58%, todo en el 60% central) y después recortado/encajado por red: X 1500×500 (con aire lateral para el avatar), Facebook 1640×624 (aire lateral, el celular recorta costados), YouTube 2560×1440 (imagen achicada dentro de la franja 1546×423), Twitch banner 1200×480 (achicada y centrada: Twitch lo estira a ~3.4:1) y offline 1920×1080.
- **Facebook**: por API — `POST /{page}/photos` (published=false) → `POST /{page}` con `cover=<id>`; foto con `POST /{page}/picture` (multipart `source`). Requiere `pages_manage_metadata` (otorgado 2026-10-03).
- **X**: `x.com/FCTOPSecret` → `[data-testid=editProfileButton]` → `[role=dialog] input[type=file]` 0 = banner, 1 = avatar → "Aplicar" → `Profile_Save_Button` vía evaluate.
- **TikTok**: perfil → "Editar perfil" → `input[type=file]` → Aplicar → Guardar; confirmar con la respuesta de `/api/update/profile/` (`status_code: 0`). A veces muestra "Hubo un problema" y aun así guarda (o al revés): verificar en pestaña nueva.
- **Twitch** (sesión agregada al Chrome CDP 2026-10-02): `dashboard.twitch.tv/u/topsecretfc/settings/channel/brand` → "Actualizar imagen de perfil" → "Cargar foto"; banners: "Cargar"/"Actualizar" abren un diálogo con `input[type=file]` adentro → "Guardar".
- **Banner de YouTube v2 (2026-10-05):** el primero (trío de ChatGPT) quedaba mal en la franja de PC (título pegado arriba, jugadores cortados en el cuello). Ahora `node scripts/banner-youtube.mjs` lo arma con los renders Brazos4: título al centro de la franja 2560×423 y 3 jugadores por lado de cabeza a cintura → R2 `_fuentes/redes/perfiles/out/youtube-banner-v2.jpg`.
- **YouTube**: desde el Chrome CDP Studio acepta las imágenes pero `channel_image_upload/*` responde 200 vacío y el cambio se revierte (falló 4 veces) → cambiar banner/foto a mano desde Studio en un navegador normal.
- **Instagram**: no hay API para la foto de perfil; a mano desde la app.
